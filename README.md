# JustReport

> A free, privacy-focused informational guide for people dealing with online abuse, harassment, fraud, and other cyber incidents.

## About

JustReport helps users understand some practical steps they can take after experiencing an online incident and guides them toward official
cybercrime reporting resources.

JustReport is an independent informational website and is **not a Government of India website**.

## Privacy

Privacy is a core part of JustReport.

- No account or signup
- No personal information collection
- No uploads
- No complaint submission through JustReport
- No database
- No tracking
- No analytics
- No complaint storage

JustReport does not receive, store, or submit complaints.

## Features

- 12 common online incident categories
- Simple incident-specific guidance
- Links to official reporting resources
- Mobile-friendly interface
- No backend required
- No user data collection

## Technology

Built using:

- HTML5
- CSS3
- Vanilla JavaScript

No frameworks or external libraries are required.
